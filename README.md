# 🎓 EduAgent АЦР — ИИ-агент для разработки образовательных программ

> **Кейс № 1 · Агенты и EdTech**

## 💡 О проекте

**EduAgent АЦР** — это веб-сервис со встроенным ИИ-агентом, который помогает методистам за 15–20 минут разрабатывать образовательные программы по любому ИТ-направлению и собирать полный комплект учебных материалов по стандартам Академии цифрового развития.

### Какую проблему мы решаем:
Обычно сборка одной программы и материалов к ней занимает от 2 до 8 недель ручного труда. При этом возникают две главные проблемы:
1. **Ошибки в арифметике часов:** часы по темам не сходятся с итоговой строкой или видами работ (лекции, практики, самостоятельная работа).
2. **Потеря связей (трассировки):** заявленные компетенции не проверяются тестами или не раскрываются в темах лекций.

**Наше решение:** Нейросеть отвечает за смысловое наполнение курса, а специальный Python-модуль автоматически пересчитывает и выравнивает часы, проверяет покрытие каждой компетенции и исключает выдуманные законы или профстандарты. Человек (методист) остаётся в контуре и утверждает каркас программы перед финальной генерацией.

## 🧩 Архитектура агента (в логике навыков GigaCowork)

Работа агента разделена на 4 последовательных навыка (Skills):

1. **Навык 1. Аналитик (Router & Clarifier):**
   * Принимает текстовый запрос методиста и файлы-референсы (`.docx`, `.pdf`).
   * Автоматически определяет нужный шаблон АЦР: **ДПП Повышения квалификации** (273-ФЗ, Приказ № 499) или **ДООП Общеразвивающая программа** (Приказ № 629).
   * Задаёт уточняющие вопросы, если в запросе не хватает объёма часов, аудитории или формы аттестации.
2. **Навык 2. Архитектор каркаса (Skeleton Builder):**
   * Формирует цель, карту компетенций (Знания, Умения, Навыки + привязка к реальным профстандартам Минтруда РФ) и учебно-тематический план.
   * **Автобалансировщик часов** выравнивает распределение часов по темам (ЛК, ПР, ЛБ, СРС) строго под запрошенный объём программы (от 16 до 500+ часов).
3. **Точка контроля (Human-in-the-Loop):**
   * Методист проверяет и при необходимости правит каркас в веб-интерфейсе перед запуском полной генерации.
4. **Навык 3. Генератор материалов (Content Factory):**
   * Создаёт содержание тем, тестовые вопросы с ключами, практические задания для семинаров с критериями оценки, планы лекций и слайды презентаций.
5. **Навык 4. Валидатор (Self-Check & Editor):**
   * Сверяет суммы часов, проверяет 100% покрытие компетенций темами и тестами, помечает неподтверждённые источники и позволяет точечно пересобрать любую тему без перегенерации всего документа.

## 🛠 Технологический стек

* **AI / ML:** Cloud.ru Evolution Foundation Models (Qwen / DeepSeek / GigaChat), OpenAI Python SDK, Pydantic, база нормативных актов и профстандартов РФ (`JSON`).
* **Backend:** Python 3.10+, FastAPI, `python-docx` (сборка программы в Word), `python-pptx` (сборка презентаций), `pypdf` (чтение референсов).
* **Frontend:** React, Vite, TypeScript.

## 🚀 Быстрый запуск проекта

### 1. Клонирование и установка зависимостей Backend / ML
```bash
git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ>
cd <ПАПКА_ПРОЕКТА>

python3 -m venv venv
source venv/bin/activate  # На Windows: venv\Scripts\activate

pip install -r requirements.txt
```

### 2. Настройка переменных окружения
Создайте файл `.env` в корне проекта:
```env
CLOUD_RU_API_KEY=ваш_ключ_cloud_ru
CLOUD_RU_BASE_URL=https://foundation-models.api.cloud.ru/v1
CLOUD_RU_MODEL=Qwen/Qwen2.5-72B-Instruct
```
*(Если API-ключ не указан, система автоматически запустится в демонстрационном режиме на эталонных структурах).*

### 3. Запуск Backend-сервера (FastAPI)
```bash
uvicorn backend.main:app --reload --port 8000
```
*Документация API (Swagger UI) будет доступна по адресу:* `http://localhost:8000/docs`

### 4. Запуск Frontend-приложения (React)
Во втором терминале перейдите в папку фронтенда и запустите клиент:
```bash
cd frontend
npm install
npm run dev
```
*Веб-интерфейс откроется по адресу:* `http://localhost:5173`
