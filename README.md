# EduAgent АЦР

Сервис для подготовки черновиков образовательных программ по кейсу АЦР,
GigaCowork и Cloud.ru. Методист утверждает каркас до создания материалов.
Окончательное утверждение программы остаётся за человеком.

В этой ветке собраны бэкенд FastAPI и интерфейс методиста React + Vite,
подключён код команды из ветки `ml`,
реализованы сохранение проектов, чтение DOCX/PDF, поэтапный API и экспорт
DOCX, PPTX, Moodle GIFT, CSV и JSON. Исходники ML-навыков не изменены.

## Быстрый запуск в Windows

Из корня репозитория, Python 3.10 или новее:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
if (-not (Test-Path .env)) { Copy-Item .env.example .env }
.\.venv\Scripts\python.exe -m uvicorn backend.main:app --reload --port 8000
```

Документация API: <http://localhost:8000/docs>.
Проверка доступности сервера: <http://localhost:8000/api/health>.

Во втором терминале, из корня репозитория, запустите интерфейс
(Node.js 22.12 или новее):

```powershell
Set-Location frontend
npm ci
npm run dev
```

Интерфейс: <http://127.0.0.1:5173>. Запросы `/api` проксируются
на локальный бэкенд с портом 8000.

По умолчанию `ML_MODE=demo`: используются демонстрационные данные ML-ветки,
без платных запросов. В режиме `cloud` нужны действующие ключ и ID модели
из выданного Cloud.ru проекта. Ошибки провайдера не подменяются демоданными.

## Проверки

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m pip check
```

Тесты проверяют интеграцию и корректность данных бэкенда. Проверка качества
курсов на пяти содержательных запросах, реальная модель Cloud.ru,
визуальная приёмка в Office и импорт в целевую Moodle выполняются отдельно.
CSV экспортируется как таблица; для импорта вопросов Moodle предназначен GIFT.

## Компоненты

| Папка       | Ответственность                                                      |
| ----------- | -------------------------------------------------------------------- |
| `backend/`  | HTTP API, хранение, разбор референсов, экспорт, контроль этапов      |
| `frontend/` | Три этапа работы методиста, ручная правка плана, просмотр и выгрузка |
| `ml/`       | Схемы команды и навыки анализа, каркаса, содержания и проверки       |
| `tests/`    | Проверки API, файлов, правок и работы с провайдером                  |

Вызовы ML-навыков используют OpenAI-совместимый
клиент с адресом Cloud.ru; обращения к сервису OpenAI не выполняются.
