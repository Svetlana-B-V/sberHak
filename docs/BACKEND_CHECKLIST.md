# Выполнение чек-листа бэкенда

Реализация использует ML-код команды из ветки `ml`, коммит `a3442f5`.
Файлы `ml/` не изменены. В режиме `demo` выполняются настоящие функции
навыков с их демонстрационными данными. Это проверка интеграции, а не
доказательство качества сгенерированного учебного содержания.

Проверено 16 октября 2026 года на Python 3.12.14 в Windows: 35 тестов
прошли, `pip check` не обнаружил конфликтов. Отдельно запущенный Uvicorn
прошёл полный HTTP-сценарий для ДПП на 72 часа и ДООП на 16 часов с
чтением DOCX/PDF, сохранением, утверждением, пятью форматами экспорта
и точечной правкой. SDK Cloud.ru проверен на тестовом HTTP-ответе;
платные модели в этих проверках не вызывались.

| Пункт команды | Реализация | Проверка |
|---|---|---|
| FastAPI, CORS и JSON проектов | `backend/main.py`, `config.py`, `storage.py` | HTTP API, разрешённый origin, сохранение и повторное чтение |
| Чтение DOCX и PDF | `backend/references.py` | Абзацы, таблицы и вложенные таблицы DOCX; текст PDF; ошибки сканов и защищённых PDF |
| Анализ запроса и файлов | `POST /api/projects/analyze` | Референсы сохраняются и доступны следующим этапам |
| Создание каркаса | `POST /api/projects/skeleton` | Вызов ML-навыка, проверка арифметики и связей, уточнения вместо скрытых 72 часов |
| Правки и утверждение | `PUT /api/projects/{project_id}/skeleton` | Вызов балансировщика, защита версии, сброс устаревших материалов |
| Создание материалов | `POST /api/projects/{project_id}/generate-content` | Запрет до утверждения, генерация по модулям, проверка комплекта |
| Точечная правка | `POST /api/projects/{project_id}/regenerate-part` | Обновляются тема и её задания, слайды затронутого модуля; другой модуль сохраняется |
| DOCX по структуре АЦР | `GET /api/projects/{project_id}/export/docx` | Оба типа, геометрия исходных шаблонов, разделы, пустые реквизиты и кадры, открытие пакета python-docx |
| Слайды PPTX | `GET /api/projects/{project_id}/export/pptx` | Открытие python-pptx, тексты и заметки, разбиение длинного содержания; просмотр рендера 10 слайдов |
| Moodle GIFT | `GET /api/projects/{project_id}/export/gift` | UTF-8, разделение вопросов, ключи, экранирование специальных символов |
| Единый эндпоинт | `POST /api/v1/evaluate` | Поэтапный протокол с явным утверждением |

Дополнительно реализованы `GET /api/projects/{project_id}`, экспорт JSON
и CSV. CSV — таблица для обработки; универсальным форматом импорта Moodle
она не заявляется. Для Moodle предназначен GIFT.

## Что ещё требует проверки команды

- Реальный вызов выданной модели Cloud.ru и замеры задержек и токенов.
- Развёртывание в выданной среде Cloud.ru.
- Просмотр DOCX в Word и PPTX в PowerPoint, особенно длинных таблиц.
  В текущем окружении нет комплектного LibreOffice, поэтому визуальный
  рендер DOCX недоступен. PPTX отрисован через Artifact Tool; PowerPoint
  не открывался. Структура обоих форматов и данные проверены.
- Импорт GIFT в целевую LMS Moodle.
- Содержательные чек-листы пяти программ и скрытые запросы жюри.

## Ограничения текущего ML-контракта

- Часы в `ml/schemas.py` имеют тип `int`. Дробные академические часы
  потребуют согласованного изменения схемы и балансировщика ML.
- Текущий балансировщик ML ограничивает ИА четырьмя часами для программ
  до 24 часов. Бэкенд отклоняет утверждение, если балансировщик меняет
  явно заданные часы ИА; скрытое изменение согласованной нагрузки запрещено.
- `SlideItem` не содержит ID темы или модуля. Бэкенд вызывает генератор по
  модулям и ведёт принадлежность слайдов отдельно; в публичном JSON слайда
  добавлено поле `module_id`.
- В демонстрационных данных содержимое курса ориентировано на анализ данных
  независимо от нового направления. Это явно обозначается как `demo`.
- Список доменов в ML-валидаторе не доказывает существование конкретного
  источника. Бэкенд помечает литературу и профессиональные стандарты как
  требующие проверки. Для ДООП поля профессиональных стандартов очищаются.
- ML-промпты и база содержат ссылку на приказ № 499. Она требует актуализации
  ML-разработчиком; бэкенд не объявляет нормативную базу подтверждённой.
- Тайминги и стоимость реальной модели пока не измерены. В деморежиме
  фактические API-вызовы и токены равны нулю, стоимость и экономия времени
  не выдумываются и представлены как `null`.

## Обработка сбоев

При ошибке генерации сохраняется утверждённый каркас. Ошибка Cloud.ru
возвращается как 502, таймаут как 504; подмена демонстрационными материалами
в режиме `cloud` запрещена. Запуск рассчитан на один процесс Uvicorn:
атомарная замена JSON защищает файл, а блокировки проектов работают внутри
этого процесса. Для нескольких worker-процессов понадобится общее хранилище
и межпроцессная координация.
