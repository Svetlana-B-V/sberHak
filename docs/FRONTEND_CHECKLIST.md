# Фронтенд: выполнение и проверка

Проверено 16 октября 2026 года. Требования взяты из трёхэтапного чек-листа
задачи фронтенда. Проверка выполнена с живым локальным FastAPI, `ML_MODE=demo`.
Бэкенд и ML-исходники при реализации интерфейса не изменялись.

## Выполненные сценарии

- ДПП ПК на 72 часа: анализ, каркас, правка, утверждение, генерация,
  просмотр, пересборка темы, пересборка вопроса, выгрузка.
- ДООП на 24 часа из неполного запроса: ответы на уточнения, прикреплённые
  DOCX и PDF, исправление названия и темы, утверждение и генерация.
  В сохранённом проекте остался извлечённый текст обоих файлов.
- Изменение одного часа показывает расхождение и отключает утверждение.
- Неподдерживаемый JSON-файл отклоняется с понятным сообщением.
- Перезагрузка восстанавливает сохранённый проект без повторной генерации.
- Запись проекта из другого клиента вызывает `409 revision_conflict`.
  Интерфейс показывает конфликт и сохраняет введённый черновик.
- Отмена обновления сохраняет локальную правку; подтверждение обновления
  заменяет её актуальной серверной версией. Отмена и подтверждение создания
  новой программы также проверены.
- На ширине 390 px общая страница не выходит за пределы экрана; широкая
  таблица и вкладки прокручиваются внутри своих областей.

Проверка выгрузок: целые ZIP-контейнеры DOCX/PPTX; заголовок программы
в DOCX; 10 слайдов PPTX по JSON; 6 вопросов GIFT и 6 строк вопросов CSV.
Исходный проект пользователя не изменялся; для мутаций создавались отдельные
тестовые проекты.

## Сборка и границы проверки

`npm run build` завершён успешно: проверка TypeScript и production-сборка
Vite. После установки зафиксированных зависимостей `npm audit` не обнаружил
уязвимостей. Отдельный автоматический набор браузерных тестов не добавлялся:
сценарии выше выполнены через управление реальным браузером.

Для приёмки всего продукта остаются реальная модель Cloud.ru, оценка качества
курсов методистом, проверка нормативных источников, импорт в Moodle,
визуальная проверка DOCX в Word и развёртывание. Нулевые демотокены
не подтверждают стоимость реальной генерации. Реальные сэкономленные часы
методиста ещё не измерялись.
